FIDELIZAÊ!

API v1

API Fidelizaê! v1

Use Authorization: Bearer SUA_CHAVE. As chaves são criadas pelo administrador em Gestão avançada → Integrações / API.

Guarde a chave e o segredo do webhook em local seguro. Eles são exibidos apenas no momento da criação.

Clientes

GET /api/v1/customers
GET /api/v1/customers/{public_id}

POST /api/v1/customers
{
  "name":"Maria Silva",
  "email":"maria@exemplo.com",
  "phone":"11999999999",
  "cpf":"12345678900",
  "birth_date":"1990-05-18"
}

Registrar compra

POST /api/v1/purchases
{
  "public_id":"mem_...",
  "amount_cents":12990,
  "idempotency_key":"pedido-8472"
}

Em pontos, o crédito segue a regra configurada. Em selos, a compra adiciona um selo. O idempotency_key evita duplicidade.

Resgatar recompensa

POST /api/v1/redemptions
{
  "public_id":"mem_...",
  "reward_id":12
}

reward_id é obrigatório para programas por pontos e dispensável para programas por selos.

Webhooks

Eventos disponíveis: customer.created, purchase.created, points.earned, stamp.earned e reward.redeemed.

Headers enviados:

X-Fidelizae-Event: purchase.created
X-Fidelizae-Signature: sha256=...

A assinatura é HMAC-SHA256 do corpo bruto usando o segredo do webhook.
